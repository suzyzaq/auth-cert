- [ ] 证据定位能跳到附件正确页码

## 附件字段重建与核对

- [ ] 附件是字段重建的第一事实源，数据库原值仅用于比对
- [ ] 授权编码、类型、层级、主体、品牌、品类、区域、日期和项目字段均可独立核对
- [ ] 每个差异字段展示数据库原值、附件值、建议值、页码、原文和置信度
- [ ] 附件未明确的字段不推测，状态为 `ATTACHMENT_FIELD_MISSING`
- [ ] 转授权不直接推断为二级授权，授权链不完整时状态为 `CHAIN_INCOMPLETE`
- [ ] 指定品类不扩大为全品类，指定区域不扩大为全国，项目授权不扩大为普通授权
- [ ] 编码、品牌、主体、附件或授权链严重冲突时，自动纠错资格为否
- [ ] 证据复核页中文显示正常，并明确提示回写已关闭

生产回写默认关闭。以上人工项目未签署前，不得设置
`WRITEBACK_ENABLED=true`。
