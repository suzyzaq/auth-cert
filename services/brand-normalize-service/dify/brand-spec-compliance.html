已知偏差 / 边界（均非阻断）

△ 别名库位置：Spec 列 BRAND_ALIAS_DATA_PATH，本实现中正式别名在 matcher.db 的 brand_alias 表内（同库），该环境变量已预留但未独立拆分（config.py:22 读取并保留，默认空）。如未来别名独立成库，填该变量即可，无需改逻辑。

△ /health 示例值：Spec 示例 alias_count:10000 仅为示意；真实库当前 alias_count=8、brand_count=122393，以实际加载为准。

＋ 响应字段为 Spec 超集：在 Spec 规定字段外，额外返回 attachment_details / source_details（含 scs_candidates），标记为「Dify 可选消费」，不影响主字段与判断。

＋ SCS 回退已含：本地未命中时查 SCS（仅启用品牌，仅作候选），属 Spec 之外的增强，且严格遵循「只作候选 / 需人工复核」。

1. 品类接口拆分：按 Spec 末段建议，将品类标准化封装为独立 POST /api/category/normalize，与品牌接口隔离，避免单点故障拖垮两类结果。

2. 生产部署：确保 Docker Desktop 运行后 bash manage.sh start 拉起容器（本次验证用本地 uvicorn 等价于容器内同款代码）。
