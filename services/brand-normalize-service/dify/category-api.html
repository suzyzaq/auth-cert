品类标准化 API · 接口与字段说明

POST /api/category/normalize —— 与品牌接口隔离部署的欧菲斯三级品类映射服务
✓ 已建成 —— 品类接口已封装并实测通过， 复用 brand-matcher 的品类匹配逻辑，数据来自 matcher.db 的 rules 表 + fallback_categories.yaml。 与品牌接口完全隔离：独立索引 / 独立 reload / 独立异常边界。pytest 品类用例 15 项通过。
隔离设计（满足「避免一个接口失败导致两类结果同时不可用」）

品牌接口

/api/brand/normalize
内存索引 BrandRepository
数据：brands / brand_alias 表
失败不影响品类

品类接口

/api/category/normalize
内存索引 CategoryRepository
数据：rules 表 + fallback yaml
失败不影响品牌

lifespan 中两个索引独立加载、各自 try/except：一个加载失败仅记录异常，不阻断另一个。 Dify 侧再拆成两个独立 HTTP 节点，实现请求级故障隔离。

请求字段（搜索过滤）
字段类型必填说明
task_typestring否固定值 category_standardization，其它值返回 INVALID_TASK_TYPE
authorization_codestring否授权书编号，透传回响应用于对账
authorization_namestring否授权书名称
product_namestring / array是*商品名称。兼容数组/单串/JSON串/逗号顿号分隔；可为空串
client_categorystring / array是*甲方类目（客户系统类目名）。格式兼容同 product_name
requirementsarray否处理要求说明（透传）

* 至少一个字段非空才有意义；两者皆空返回 unmatched + needs_manual_review=true。批量时按首个非空元素一一配对，完整结果在 details。

响应字段（搜索过滤）
字段类型说明
successboolean处理是否成功
authorization_codestring透传的授权书编号
kind1string欧菲斯一级类目
kind2string欧菲斯二级类目（中类）
kind3string欧菲斯三级类目（小类），主数据落点
category_matchedboolean是否命中欧菲斯小类（status=matched 且 kind3 非空）
category_sourcestring命中来源：product_name/client_category/fallback/legacy_fallback
category_match_kindstringkeyword/synonym/hierarchy_l3/contain/fuzzy/fallback/legacy_score
confidencenumber置信度 0–1（兜底/fuzzy 命中为 1.0 / 阈值分）
matched_termstring命中的关键词 / 兜底规则 id
statusstringmatched / unmatched
suggestionstring未匹配时的建议（人可读）
needs_manual_reviewboolean是否需人工复核（status≠matched 或 kind3 空时为 true）
error_codestring空 / INVALID_TASK_TYPE / HTTP_xxx
messagestring处理说明
detailsarray逐条 (商品名,类目) 配对明细，批量时一一对应
示例 
curl -X POST http://HOST:8000/api/category/normalize \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <BRAND_API_TOKEN>" \
  -d '{"task_type":"category_standardization","client_category":"茶杯"}'
# -> {"success":true,"kind3":"陶瓷杯","category_source":"fallback",
#     "category_matched":true,"confidence":1.0,"status":"matched"}
Dify 节点配置（独立 HTTP 节点） 
方法: POST
URL:  http://HOST:8000/api/category/normalize
Header: Content-Type: application/json
Header: Authorization: Bearer {{#env.BRAND_API_TOKEN#}}
超时:  连接 5s / 读取 10s
重试:  1 次

Body:
{
  "task_type": "category_standardization",
  "authorization_code": "{{#start.authorization_code#}}",
  "product_name": "{{#attachment_extract.product_name#}}",
  "client_category": "{{#db_query.client_category#}}"
}

条件分支:
  category_matched==true AND needs_manual_review==false -> 自动通过品类项
  category_source=="fallback"                            -> 命中兜底(如茶杯→陶瓷杯),建议沉淀
  needs_manual_review==true                             -> 转人工复核(钉钉AI表格队列)
